# 谁是小丑 - Who Is The Clown

仿 CF 穿越火线“谁是小丑”模式的第一人称 3D 网页游戏，支持手机触控、桌面操作和 WebSocket 房间联机。

## 技术栈
- **React 18** + **Three.js r128**
- **Node.js + WebSocket** 房间服务器
- Vite 构建，可用同一个 Node 服务托管网页和联机连接

## 快速开始
```bash
npm install
npm run dev
```

运行完整回归检查：

```bash
npm test
```

## 项目结构
```
src/
  Game.jsx              # 单人玩法和行为状态机

  combat.js             # 近战角度、射线命中和掩体判定
  suspicion.js          # 基于可观察行为的嫌疑系统
  characters.js         # 角色模型和动画
  fpsPresentation.js    # 第一人称武器、音效和反馈
  App.jsx               # 模式入口
server.js               # 静态托管和 WebSocket 房间服务
scripts/                # 回归测试
index.html
package.json
vite.config.js
README.md
```

## 已实现功能

### 核心玩法
- 第一人称视角，手机触控（左摇杆移动，右侧滑动转视角）+ 桌面WASD+鼠标
- 两个阵营：小丑 vs 警察
- 玩家初始为小丑，被击杀后变身警察继续游戏
- 小丑一击必杀警察（近战），警察需要两枪杀死真小丑
- 6个钱包点分散在地图四角，占领5个获胜，占领需3秒读条

### AI系统
- **AI小丑**（10个，其中3个是"真小丑"）：
  - 闲逛、曲线移动、观察四周、结伴、检查钱包、逃离警察等伪装行为
  - 真小丑额外拥有偷钱包、占领钱包和追杀警察行为
- **警察AI**（3个）：
  - 巡逻、守卫、关注、调查、跟踪、追击和搜索最后目击位置
  - 只根据视野内的奔跑、靠近/占领钱包、逃跑和攻击等行为累积嫌疑，不读取隐藏身份
  - 证据达到“确认”阶段后才会开枪，普通行为不会被随机识破
  - 误杀扣30HP，误杀过多会自己死亡
- 寻路会绕过建筑、保持队形间距，并在卡住时自动换边和重新规划

### UI/HUD
- HP、时间、钱包数、存活数、阵营标签
- 击杀播报（左侧feed）、钱包进度条（右上5格）
- 小地图（建筑、钱包状态、玩家位置。警察模式额外显示队友）
- 准星、占领进度条

### 特殊机制
- 疯狂时刻（最后60秒，大量AI涌入）
- 白天场景、人形角色模型、走路动画
- 第一人称武器、枪口反馈、命中粒子、脚步和战斗音效
- 近战扇形、真实射线命中和建筑掩体阻挡

### 胜负条件
- 小丑胜：占5钱包 / 消灭所有警察
- 警察胜：消灭所有真小丑 / 时间到钱包没占满
- 变身：小丑被杀→警察(50HP)

## 已知问题

### Bug
1. 碰撞和建筑掩体仍使用 AABB，斜角处偶尔会显得生硬
2. 多人模式仍是客户端判定战斗，尚未加入服务器权威位置与延迟补偿
3. 首次载入的 Three.js 包体较大，弱网下进入游戏会偏慢

## 多人联机

架构：`React + Three.js <--WebSocket--> Node.js`

项目已经包含创建/加入房间、房主设置人数、角色分配、位置同步、攻击、钱包和重开投票。生产部署可直接使用仓库中的 `render.yaml`。

下一步重点：服务器权威战斗、插值与延迟补偿、断线重连和观战。

## 配置参数（CFG对象在Game.jsx顶部）

| 参数 | 值 | 说明 |
|------|-----|------|
| MAP | 60 | 地图大小 |
| WALK/SPRINT | 4/7 | 走路/疾跑速度 |
| AI | 10 | AI小丑数（前3个是真小丑）|
| COPS | 3 | 警察数 |
| WIN_W | 5 | 需占领钱包数 |
| COL_T | 3 | 占领耗时(秒) |
| TIME | 240 | 总时间(秒) |
| RAGE_T | 60 | 疯狂时刻触发(剩余秒) |
| PV/PA | 12/π*.55 | 警察视野距离/角度 |
| PSD | 20 | 警察每枪伤害 |
| PMK | 30 | 误杀AI惩罚HP |
| AD | 100 | 小丑攻击伤害(一击必杀) |
